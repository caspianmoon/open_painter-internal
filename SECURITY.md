# Security

Please report security issues privately, not in public issues: use GitHub's
**Report a vulnerability** button on this repository's Security tab, or email
support@openpainter.dev. We'll acknowledge the report and keep you informed while we fix it.

Open Painter runs inside Blender with your user's permissions. It reads and writes the
files you choose and, only if you connect Material Director, downloads and runs the OpenAI
Codex CLI (see the README's privacy section).
